MIXE 2.0.0 is a new email client. The previous emulator shell is replaced.

- Add any IMAP/SMTP account (multiple accounts supported)
- Receive mail, browse folders, read messages, save attachments
- Compose, Reply, Reply All, Forward
- Mark read/unread and delete
- Per-user install (no admin) plus a standalone portable exe

Some providers (for example Gmail or Outlook) need an app password.
