# MIXE 1.0.0

First release — BlueStacks-style shell around QEMU + Android-x86.

- Home / My Apps / Install APK / Keys / Settings
- Sidebar: Back, Guest Home, Recents, Rotate, Volume, Shake
- Bundled QEMU (x86_64) + adb; Android-x86 ISO downloaded on first run (SHA-1 verified)
- Virtualization detection with WHPX preference and clear BIOS / Windows Features guidance
- Shared folder at Documents/MIXE/Shared
- No Google Play Services
