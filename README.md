# MIXE

**MIXE** is a desktop email client by EX Inc. Add any IMAP and SMTP account, then send and receive real mail on your Windows PC.

- Multiple accounts, stored only on this PC
- Folder list (Inbox and the rest of the mailbox)
- Read messages, save attachments
- Compose, Reply, Reply All, Forward
- Refresh, mark read or unread, delete

Some providers (for example Gmail or Outlook) require an app password instead of your regular password.

## Requirements

- 64-bit Windows 10/11
- An email account with IMAP and SMTP access

## First run

1. Install MIXE (or run the portable exe).
2. Click **Add account** and enter your display name, address, password or app password, and IMAP/SMTP server details.
3. Use **Test connection** if you want to verify the settings, then **Save**.
4. Open a folder to read mail, or click **Compose** to send.

## Honesty note

The build machine tests the app under Wine: the window, account dialog, and compose window. Live send and receive need a real mailbox on a real Windows PC.
